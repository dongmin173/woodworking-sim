# 작은 목공 작업실 — P2 첫 구현

HTML/CSS/JavaScript + Paper.js 0.12.18로 만든 평면 목공 데모입니다.

## 실행

ZIP을 압축 해제하고 woodworking-sim/index.html을 Chrome 또는 Edge로 열면 됩니다.
외부 폰트, CDN, npm, 빌드 과정이 필요하지 않습니다.

선택: Python이 설치되어 있으면 이 폴더에서 PowerShell을 열고 실행합니다.

```powershell
py -m http.server 8000
```

http://localhost:8000 에 접속합니다. 서버 종료는 Ctrl+C입니다.

## 조작

1. 이동 도구를 선택하고 아래 작업 판자를 위 기준 판자 아래의 점선에 맞춥니다.
2. 왼쪽 끝과 높이가 목표 위치에서 24 논리 단위 이내면 놓을 때 자동 정렬됩니다.
3. 연필을 선택하고 작업 판자를 클릭하면 기준 판자의 오른쪽 끝 위치에 선이 생깁니다.
4. 톱을 선택하고 선을 클릭하면 두 조각으로 잘립니다. 선 선택 허용 거리는 8 논리 단위입니다.
5. 이동 도구로 각 조각을 움직일 수 있습니다. 선을 그은 뒤 이동해도 선이 따라옵니다.
6. 스테이지 선택/화살표로 자유롭게 이동합니다. 현재 페이지를 유지하는 동안 스테이지별 상태가 보존됩니다.
7. Reset은 현재 스테이지만 초기화합니다. 새로고침은 모든 상태를 초기화합니다.

## 파일 역할

- index.html: 화면과 도구 버튼, 스크립트 로딩
- style.css: 작업대와 반응형 화면
- stages.js: 길이가 다른 세 스테이지
- wood.js: 판자의 다각형 데이터, 그리기, Paper.js 교집합 절단
- app.js: 드래그, 스냅, 도구 모드, 좌표 변환, 스테이지 상태
- vendor/: 수정하지 않은 Paper.js와 MIT 라이선스
- SOURCES.txt: 오픈소스 출처
- AI_USAGE.md: 현재 구현에서의 AI 사용 기록

## 구현 원리와 범위

판자는 위치(x, y)와 판자 내부 좌표의 꼭짓점으로 저장합니다.
연필선은 내부 X 좌표로 저장하므로 판자 이동을 따라갑니다.
톱은 현재 다각형과 절단선 양쪽을 덮는 직사각형의 교집합을 각각 구합니다.
첫 버전은 회전 없는 직사각형과 세로 방향의 관통 절단만 지원합니다.
wood.js의 cut()도 이 범위를 전제로 합니다. 오목 다각형과 구멍을 지원하려면
CompoundPath와 여러 분리 영역의 처리를 확장해야 합니다.
스테이지는 길이만 다르고, 클리어 판정이나 잠금은 없습니다.
